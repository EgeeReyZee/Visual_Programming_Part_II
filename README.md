Вторая часть проекта по дисциплине **«Визуальное программирование»**. Приложение представляет собой высокопроизводительную десктопную систему для визуализации географических карт, интерактивного анализа пространственных данных и динамического построения тепловых карт (Heatmaps)[cite: 2].

Проект спроектирован с использованием клиент-серверной архитектуры (компоненты на C++ и скрипты автоматизации на Python)[cite: 2].

---

## 🚀 Основные модули и возможности

*   **Графический движок (`gui.cpp`, `main.cpp`):** Интерактивный интерфейс на базе **Dear ImGui** и окна вывода с аппаратным ускорением через **GLFW**[cite: 2]. Для загрузки и рендеринга текстур карт используется библиотека `stb_image.h`[cite: 2].
*   **Тепловые карты (`heatmap.cpp`):** Аналитический модуль, отвечающий за расчет плотности точек, генерацию координатных сеток и отрисовку тепловых карт интенсивности с помощью библиотеки **ImPlot**[cite: 2].
*   **Картографический модуль (`map.cpp`):** Слой управления подложками карт, привязки экранных координат к географическим и отображения маркеров[cite: 2].
*   **База данных (`db.cpp`, `postgres/`):** Интеграция с СУБД **PostgreSQL** для долговременного хранения логов, координат, сессий и пространственных метаданных[cite: 2].
*   **Сетевой слой (`server.cpp`, `zeromq/`):** Высокопроизводительный сервер обмена сообщениями на базе **ZeroMQ**, принимающий потоковые геоданные от внешних клиентов[cite: 2].
*   **Примеры и симуляторы (`examples/`):** Набор скриптов (`client.py`, `server.py`, `client.c`) для симуляции отправки телеметрии и проверки сетевой связности[cite: 2].

---

## 🛠 Технологический стек

*   **Core:** C++17, Смарт-пойнтеры, Многопоточность[cite: 2].
*   **GUI & Рендеринг:** Dear ImGui (Docking branch), ImPlot (для продвинутых графиков плотности), GLFW[cite: 2].
*   **Сетевой стек:** ZeroMQ (библиотека межпроцессного и сетевого взаимодействия)[cite: 2].
*   **БД:** PostgreSQL Client библиотека[cite: 2].
*   **Вспомогательные инструменты:** `json.hpp` (Nlohmann JSON для парсинга конфигураций), `stb_image` для декодирования растровых изображений карт[cite: 2].
*   **Скрипты:** Python 3 (для генерации синтетического потока координат клиентов)[cite: 2].

## 🔧 Инструкция по сборке и запуску

### Системные требования

* Компилятор с поддержкой **C++17** (GCC 9+, Clang 10+, MSVC 2019+).
* Установленный **CMake** версии 3.15 или выше.


* Библиотека и сервер **PostgreSQL**.



### Шаг 1: Клонирование и обновление субмодулей

Так как проект использует внешние зависимости в виде подмодулей, клонируйте репозиторий с флагом `--recursive`:

```bash
git clone --recursive [https://github.com/EgeeReyZee/Visual_Programming_Part_II.git](https://github.com/EgeeReyZee/Visual_Programming_Part_II.git)
cd Visual_Programming_Part_II
git checkout develop

```

### Шаг 2: Сборка C++ проекта

```bash
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --config Release

```

### Шаг 3: Запуск и симуляция данных

1. Запустите собранное бинарное приложение (оно поднимет GUI окно и ZeroMQ сервер).


2. Для проверки отображения тепловой карты запустите скрипт-эмулятор из папки `examples/`, который начнет генерировать и отправлять случайные гео-координаты:



```bash
   python3 examples/client.py

```
